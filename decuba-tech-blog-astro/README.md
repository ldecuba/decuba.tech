# decuba.tech

Personal blog built with Astro and TypeScript-friendly components. Posts can live in Markdown and the site deploys as static files.

## Cloudflare Pages

Use these settings when connecting the repository:

- Framework preset: `Astro`
- Build command: `npm run build`
- Build output directory: `dist`
- Node.js version: `22`

Cloudflare Pages can deploy automatically on every push to the selected production branch. The generated site does not need a server or database.

## Local preview

```text
npm install
npm run dev
```
