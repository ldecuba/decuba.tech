# Decuba Tech Blog WordPress Theme

This is a lightweight WordPress block theme for decuba.tech. It is built for an AI and Microsoft technology blog with editable templates, reusable homepage patterns, and category-first navigation.

## Install

1. Zip the `decuba-tech-blog` folder.
2. In WordPress, go to Appearance > Themes > Add New > Upload Theme.
3. Upload the zip, activate the theme, then open Appearance > Editor.

## Recommended Categories

- AI
- Microsoft 365
- M365 Copilot
- Power Platform
- Power Apps
- Power Automate
- Dataverse
- Power Pages
- Copilot Studio
- Power BI

## Maintenance Notes

- Use featured images on posts for the best archive layout.
- Edit the homepage in Appearance > Editor > Templates > Home.
- Edit navigation in Appearance > Editor > Navigation.
- Keep long-running article series in categories, not hardcoded pages.
- Replace `assets/images/decuba-tech-hero.png` if you want a different hero or social preview image.

## Suggested WordPress Plugins

- Yoast SEO or Rank Math for search metadata.
- Redirection for URL migration from the current site.
- WP Rocket, LiteSpeed Cache, or the host's caching plugin for performance.
- Akismet or Antispam Bee for comment spam control.
